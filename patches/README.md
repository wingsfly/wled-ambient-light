# 对上游 `wled00/` 的本地补丁

**默认纪律仍然是「上游一个字都不改」**（理由见 `tools/hostwled/README.md`：
模拟器存在的唯一价值是「看到的就是将来会看到的」）。这个目录记录**例外**。

每打一个补丁：

1. 在改动处留 `// [lamp-fork] see patches/NNNN` 标记 —— 将来跟上游合并时，
   冲突现场就能看出这是本地补丁而不是别人的改动。
2. 在这里加一个 `NNNN-简述.md`，写清楚**是什么 bug、怎么复现、为什么不
   绕过它**。
3. 上游修好之后**要把补丁撤掉**，别让它无限期留着。

查当前所有补丁点：

```bash
grep -rn "\[lamp-fork\]" wled00/
```

`tools/build_wled.sh` 末尾的 `git diff --quiet wled00/` 自检**照旧有效**：
它比的是工作区与索引，拦的是「构建脚本顺着软链写穿了上游文件」这类事故。
已提交的补丁不会触发它。
